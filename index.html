GREEN PACKAGE SKILL

k3s

Provision one Hetzner VPS with a restrictive firewall, pinned K3s and Flux releases, and reconciliation from a public Git repository. The Kubernetes API remains private; kubectl runs over managed SSH.

npx skills add getcolors/k3s
cp .agents/skills/package-k3s-green/green green
./green build
./green create --dry-run
./green kubectl get nodes

Optional Cloudflare integration bootstraps ExternalDNS and cert-manager credentials without rendering the token.
